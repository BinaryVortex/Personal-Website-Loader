# Personal Website Loader

A simple personal website loader built using HTML, CSS and JavaScript.

![Demo screenshot](./Screenshot%202024-08-28%20143529.png)

## Overview

This repository contains a lightweight loader page for a personal website. It demonstrates a small, self-contained HTML/CSS/JS project that shows a loading animation and then displays the site content.

## Features

- Minimal, dependency-free HTML/CSS/JS
- Simple loader/transition animation
- Easy to customize and integrate into personal sites

## Quick Start

1. Clone the repository:

   git clone https://github.com/BinaryVortex/Personal-Website-Loader.git

2. Open `index.html` in your browser (double-click or serve with a static server):

   - Double-click `index.html`, or
   - Run a local server (recommended):
     - Python 3: `python -m http.server 8000`
     - Then open `http://localhost:8000` in your browser

## Customize

- Edit `index.html` to change text, structure, or content.
- Update styles in the `<style>` block or external CSS file if added.
- Modify or replace the loader animation in the JavaScript section.
